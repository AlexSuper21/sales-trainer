Следующий этап [[0 Воронка и цели|воронки]] — «Квалифицирован». На эту стадию переводятся сделки, по которым уже [[4 Встреча проведена|проведена]] квалификация и получены ответы по следующим обязательным параметрам:

- **Расположение участка:** указывается конкретный адрес; если участка нет — ставится пометка «участка нет».
    
- **Материал строительства:** выбирается один из трёх вариантов — клееный брус, каменный, каркасный.
    
- **Планируемый срок начала строительства:** выбирается один из трёх — в ближайшее время, через три месяца, через год.
    
- **Бюджет и форма оплаты:** выбирается один из трёх — наличный расчёт, ипотека, сертификат.
